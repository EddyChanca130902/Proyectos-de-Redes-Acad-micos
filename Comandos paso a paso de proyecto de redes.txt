PROYECTO RED EMPRESA SOPORTE TI - COMANDOS CISCO
============================================================

IMPORTANTE ANTES DE PEGAR EN FISICO:
1. Verifica nombres de interfaces en cada equipo:
   show ip interface brief
   show interfaces status
2. En equipos fisicos los puertos pueden cambiar, por ejemplo:
   G0/0/0 puede ser G0/0 o G0/1 segun modelo.
3. En enlaces seriales, solo el lado DCE lleva clock rate:
   show controllers serial0/1/0
   show controllers serial0/1/1
4. Si una interfaz esta administratively down, entra a la interfaz y coloca:
   no shutdown
5. Guarda siempre con:
   write memory

description ENLACE_A_SEDE_IZQUIERDA

no auto-summary

end

============================================================
2) R-SEDE1 - ROUTER SEDE PRINCIPAL
Router-on-a-Stick + DHCP + RIP
============================================================

enable
configure terminal
hostname R-SEDE1

interface gigabitEthernet0/0/0
description ENLACE_A_R-PRINCIPAL-WAN
ip address 10.0.12.2 255.255.255.252
no shutdown
exit

interface gigabitEthernet0/0/1
description TRUNK_A_SW-SEDE1-CORE
no ip address
no shutdown
exit

interface gigabitEthernet0/0/1.10
description VLAN_10_SOPORTE
encapsulation dot1Q 10
ip address 192.168.10.1 255.255.255.0
exit

interface gigabitEthernet0/0/1.20
description VLAN_20_ADMINISTRACION
encapsulation dot1Q 20
ip address 192.168.20.1 255.255.255.0
exit

interface gigabitEthernet0/0/1.99
description VLAN_99_NATIVA
encapsulation dot1Q 99 native
ip address 192.168.99.1 255.255.255.0
exit

ip dhcp excluded-address 192.168.10.1 192.168.10.20
ip dhcp excluded-address 192.168.20.1 192.168.20.20
ip dhcp excluded-address 192.168.99.1 192.168.99.20

ip dhcp pool VLAN10_SOPORTE
network 192.168.10.0 255.255.255.0
default-router 192.168.10.1
dns-server 8.8.8.8
exit

ip dhcp pool VLAN20_ADMINISTRACION
network 192.168.20.0 255.255.255.0
default-router 192.168.20.1
dns-server 8.8.8.8
exit

router rip
version 2
no auto-summary
network 10.0.0.0
network 192.168.10.0
network 192.168.20.0
network 192.168.99.0
exit

end
write memory

14) CLOCK RATE EN SERIALES
============================================================

En cada router con serial, verificar DCE:

show controllers serial0/1/0
show controllers serial0/1/1

Si una interfaz es DCE, colocar clock rate solo en ese lado:

configure terminal
interface serial0/1/0
clock rate 64000
no shutdown
exit
end
write memory

O si es serial0/1/1:

configure terminal
interface serial0/1/1
clock rate 64000
no shutdown
exit
end
write memory

18) PRUEBA DE PORT SECURITY
============================================================

En SW-SEDE3, la PC cableada esta en Fa0/1.
Primero conectar la PC autorizada y verificar:

show port-security interface fastEthernet0/1
show running-config interface fastEthernet0/1

Luego conectar otra PC distinta en Fa0/1.
El puerto debe bloquearse.

Para recuperar el puerto:

enable
configure terminal
interface fastEthernet0/1
shutdown
no shutdown
exit
end
write memory

Para borrar sticky MAC y volver a probar:

enable
configure terminal
interface fastEthernet0/1
shutdown
no switchport port-security mac-address sticky
switchport port-security mac-address sticky
no shutdown
exit
end
write memory

============================================================
19) NOTAS PARA LABORATORIO FISICO
============================================================

1. Si un router tiene puertos EtherSwitch, no permiten subinterfaces.
   Para Router-on-a-Stick usa un puerto routed real, no un puerto switchport.

2. Si al entrar a una interfaz aparece switchport, es puerto de switch.
   Si permite ip address directamente, es puerto de router.

3. Para verificar:
   show running-config interface gigabitEthernet0/0/1
   show ip interface brief

4. En fisico, revisa cableado, duplex, speed e interfaces:
   show interfaces
   show controllers
   show version
   show inventory

5. Si un puerto serial queda up/down:
   revisar clock rate en el lado DCE.

6. Si queda administratively down/down:
   falta no shutdown.

7. Si queda down/down:
   cable incorrecto o interfaz equivocada.
